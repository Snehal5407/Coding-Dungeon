# CODING DUNGEON

Retro pixel-art C++/OOP learning RPG.

## Run
1. Extract this folder.
2. Open the `CodingDungeon_Web_OOP_Final` folder.
3. Double-click `Open_Game.bat`.
4. The game opens in your browser and starts on the main menu.

Do not open the CPP files to run the web game. The `cpp` folder contains the OOP implementation/model for the college project.

## Features
- 100 levels and progressive difficulty
- C++ and OOP learning questions
- Non-repeating question selection until the question pool is exhausted
- RPG battle, XP, coins, streaks, bosses and save progress
- Separate Code Crossword word-search mode in the main menu
- Unlock one crossword for every 5 completed adventure levels (10 puzzles unlock by level 50)
- Find hidden C++/OOP words by selecting letters across, down or diagonally; no answer typing
- Word-search hints and XP/coin rewards
- Responsive/mobile-friendly UI and sound
